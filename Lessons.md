# README (usage notes)
> For Claude: this is the master lesson index. When a new lesson is planned, add a row here first (Not Started), then create `./Lessons/Lesson N (Name)/LessonPlan.md` and link it. Keep descriptions to one line — detail belongs in the LessonPlan. Update Status as the lesson progresses. Curriculum Items use the outline numbering from `Curriculum.md` (e.g. `3.2` = section 3, sub-item 2).
