# README (usage notes)
> For Claude: update this table after lessons, evaluations, or any interaction that changes your read of the user's grasp of a curriculum item. Every change to the table must also get a row in the Change Journal below — old %, new %, and why. Curriculum Items use the outline numbering from `Curriculum.md` (e.g. `3.2`). Don't add rows for items that haven't been touched yet; start a row once a lesson has introduced the item, or once a placement diagnostic has tested it (diagnostics can populate real, above-0% scores for things the user already knew coming in).
> For the human: this is a running self-assessment, not a graded score — it reflects Claude's best guess of your understanding, informed by lessons and evaluations.
