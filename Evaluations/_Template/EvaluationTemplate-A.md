# README (usage notes)
> For Claude: write the actual questions here once `EvaluationPlan.md`'s Scoring Criteria and Question Plan are filled in. This file must stay answer-free — it's what the user fills out directly. Mirror it question-for-question in `AnswerKey-A.md`, including the `**Grade:**` line. For a scramble, copy this file to `EvaluationTemplate-B.md` (next unused letter) and write new questions that hit the same Question Plan. When grading a copy of this file (`Attempt-A1.md`, `Attempt-A2.md`, etc. — the attempt's number always follows this file's version letter), fill in each `**Grade:**` line (Correct / Partial / Incorrect + a one-line reason) directly below the matching answer — that's the durable record of per-question feedback; `EvaluationPlan.md`'s Attempts & Results table only holds the rollup score.
> For the human: copy this file to `Attempt-A1.md` (A = this file's version letter, 1 = attempt number, starting at 1) before filling it out — don't edit this template in place, and don't open `AnswerKey-A.md` first. Fill in your answer under each question (leave `**Grade:**` blank, that's for grading), then ask to be graded.
