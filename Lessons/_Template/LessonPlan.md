# README (usage notes)
> For Claude: copy this folder to `./Lessons/Lesson N (Name)/` when starting a new lesson, fill it in, and link it from `Lessons.md`. This file itself is the doc that `Kanban.md`'s "Active Tasks NOW" should link to while the lesson is in progress — don't create a separate task stub for it. Any files generated while running the lesson (scripts, transcripts, exercise output) go in that same lesson folder, never here. Keep the lesson scoped to a single functional scenario — if it's covering unrelated curriculum items, split it into two lessons. Update Session Notes after each outline step (not just at session end) so a context compaction or a fresh session can pick up cleanly — and update `Kanban.md` / `Lessons.md` Status together whenever this lesson's state changes.
> For the human: this is the walkthrough for the lesson — read top to bottom or let Claude drive it interactively.
