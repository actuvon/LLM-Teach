# README (usage notes)
> For Claude: read this file first, every session, before responding to anything (see `CLAUDE.md`). "Active Tasks NOW" links directly to the file that describes current work — if the work is a lesson or evaluation, that link is the `LessonPlan.md`/`EvaluationPlan.md` itself, not a separate stub. This file is the *right-now* state; `Lessons.md`/`Evaluations.md` are the *durable ledger* (status, history). When a lesson's status changes, update both here and there in the same edit — don't let them disagree. Keep "Recently Completed" capped at ~10 entries: when adding one would exceed that, move the oldest into `./ActiveTasks/Archive/CompletedLog.md` and its detail file(s) into `./ActiveTasks/Archive/`. This file gets loaded in full every session, so it must stay small — full history lives in `CompletedLog.md`, not here.
> For the human: this is the state machine Claude reads to know where things stand. If a session gets interrupted, this file is how the next session picks back up. Full completed-task history is in `./ActiveTasks/Archive/CompletedLog.md`, not here.
